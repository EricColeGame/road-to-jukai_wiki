## ダンジョンシステム：視認可能なエンカウントと霧の種類

見えないランダムエンカウントのみに依存するクラシックなダンジョンRPGとは異なり、本作の迷宮ではグリッド上の視認可能な霧マスによって戦闘が予告されます。霧の色に注意を払うことで、戦闘マスに踏み込む前にパーティの準備を整えることが可能です。

戦闘に入る前に敵の脅威度を把握できれば、強化バフをかけるか、回復するか、あるいは一度街に戻って経験値を確保するかを的確に判断できます。

| 霧の種類 | 脅威度 | 出現する敵の構成 | 推奨される準備 |
| :--- | :--- | :--- | :--- |
| **灰色の霧** | 低〜中 | 通常の雑魚敵、徘徊する群れ、小型のゴブリン | 基本攻撃の順序を確認、ボス戦用にMPを温存 |
| **赤色の霧** | 高〜致命的 | エリート敵、レア出現（例：Moto Inu / 本犬など）、中ボス | パーティ全員にバフ付与、セーブまたはフロア切り替え |
| **イベントマス** | 変動 | 会話イベント、任意の挑戦（Hettsui Yurei / 竈幽霊） | HPを満タンにし、攻撃術士のスペル枠を確保 |

プレイヤーのプレイ経験やコミュニティの報告によると、ストーリーに関係のない赤霧のエンカウントは、フロアを移動したり街に戻ったりするたびにリスポーンします。パーティの戦力を大きく削る凶悪な赤霧エンカウントに遭遇した場合は、戦いを挑む前に迷宮の階層を切り替えて安全を確保することも検討しましょう。

## 樹海への道の主要な敵解説

序盤の迷宮では、大群でのエンカウント、後衛を狙うスナイパー、高火力の術士などが混ざって出現します。**樹海への道の敵**の中でターゲットの優先順位を正しく見極めることが、長丁場の探索における無駄な犠牲を防ぐ鍵となります。

```
                  [ 前衛の敵集団 ]
                 /                  \
   [ ゴブリンの群れ / ボス ]       [ Moto Inu (術士) ]
        |                              |
    近接中心 / 敵数が多い           単体大ダメージ (20+ DMG)
        |                              |
     後衛を保護                      最優先で速攻撃破
```

### 1. ゴブリンの群れとゴブリンリーダー（The Goblin Swarm and Goblin Leader）
マップの中央西寄り、警告を発する衛兵の先で、灰色の霧による大規模な固定エンカウントが発生します。この戦闘では、手強いボスゴブリンに率いられた約10体の通常ゴブリンが出現します。

* **行動パターン:** 通常のゴブリンは隊列のどの列にも攻撃を届かせてくるため、体力の低い魔法使いなどが格好の標的になります。
* **ボス:** 完全な近接攻撃のみを行います。前衛のゴブリンを倒していくにつれて、リーダーが徐々に前進してきます。
* **対策:** 前衛のHPを常に50%以上に保ち、各個撃破して敵の手数を素早く減らしていきましょう。

### 2. Moto Inu / 本犬（赤霧のエリート敵）
Moto Inuは、このエリアで遭遇する最初期の非常に危険な**樹海への道の敵**の一角です。魔法を操る獣であり、魔法防御の低いキャラクターにとって直接的な脅威となります。

* **火力:** ランダムなパーティメンバー1体に対して、1回の詠唱で20以上のダメージを与えてきます。
* **危険度:** 序盤のレベル帯において、20ダメージは魔法職が一撃で戦闘不能または即死するのに十分な数値です。
* **対策:** 素早さの高い物理スキルや高威力の魔法を最優先で叩き込み、1ターン目に魔法を使われる前に撃破しましょう。

### 3. Hettsui Yurei / 竈幽霊（北西の任意イベント）
北西の角には任意のイベントマスが隠されています。調べて「はい（Yes）」を選択すると、高い物理耐性を持つ霊体「Hettsui Yurei」との戦闘が始まります。

* **強み:** 通常の武器攻撃に対する高い物理回避率と防御力。
* **弱点:** 攻撃属性魔法に対して極めて脆弱。
* **戦術:** メインの術士に攻撃魔法を連打させ、物理アタッカーは防御に徹するか攻撃用消費アイテムを使用させましょう。

| 敵の名称 | 出現タイプ | 主な攻撃スタイル | 最も危険な対象 | 最適な対策 |
| :--- | :--- | :--- | :--- | :--- |
| **劣等ゴブリン（Lesser Goblins）** | 灰色の霧 / 集団 | 遠隔＆近接攻撃 | 後衛の術士 | 素早い通常攻撃、列攻撃スキル |
| **ゴブリンリーダー（Goblin Leader）** | 固定イベント集団 | 強力な近接攻撃 | 前衛のタンク | 防御スタンス、集中攻撃 |
| **Moto Inu** | 赤色の霧（レア） | 単体への強力な魔法攻撃 | 耐久の低い後衛キャラ | 即座のバースト火力、事前の強化バフ |
| **Hettsui Yurei** | 北西イベントマス | 霊的・非実体攻撃 | 物理アタッカー | 攻撃魔法の連打、神聖/属性ダメージ |

## 序盤迷宮を生き抜くための必須戦闘戦術

**樹海への道の敵**との戦闘を乗り切るには、的確なパーティ管理と、本作独自の属性（アライメント）や墨による侵食システムの理解が必要です。

### エンカウント時の選択肢：「攻撃」「様子を見る」「無視する」の対処法
一部の戦闘では、1ターン目が始まる前に状況に応じた選択肢が表示されます。この選択はキャラクターのアライメントに直接影響を与えます。

* **攻撃する（Attack）:** キャラクターが**悪（Evil）**に傾く可能性があります。
* **無視する（Ignore）:** キャラクターが**善（Good）**に傾く可能性があります。
* **様子を見る（Wait）:** 完全に中立です。パーティのアライメントは変化しません。

クラスの要件を維持し、意図しないアライメントの変化を防ぐため、コミュニティではこれらのプロンプトが表示されたら常に**様子を見る（Wait）**を選択することが強く推奨されています。

### 墨の侵食（Ink Affliction）の管理
戦闘中、敵の攻撃によって「墨の侵食」を受けることがあります。これによりキャラクターの最大HPが直接減少します。このデバフは戦闘終了後も持続します。

| 状態異常 | ステータスへの影響 | 回復方法 | 場所 | コスト |
| :--- | :--- | :--- | :--- | :--- |
| **墨の侵食（Afflicted by Ink）** | 最大HPが一時的に低下 | 浄化の儀式 | 街の寺院 | 少額の金 |
| **行動不能 / 死亡（Fallen / Dead）** | 行動不能 | 蘇生の儀式 | 街の寺院 | 中程度の金 |
| **ステータス低下（レベルアップ時）** | ランダムに能力値が低下する可能性 | フロアリロードによる厳選 | 迷宮の階段 | 無料（リロードが必要） |

街に戻ったら必ずすぐに寺院へ立ち寄り、墨の侵食を浄化して、万全の状態で次の戦闘に挑めるようにしましょう。

## ルート攻略と探索のポイント

マップの構造自体はコンパクトですが、隠されたショートカットを見落としたり、闇雲に突進したりすると、リソースが尽きてパーティが立ち往生する危険があります。

```
[開始地点] ---> [衛兵 / 警告] ---> [ゴブリンの群れ (西)]
                                            |
                                  [南のショートカット開通]
                                            |
[山麓樹海への出口 (北東)] <--- [船頭] <--- [中央ルート]
          |
   (エリアを踏んで
  ファストトラベル解放)
```

1. **衛兵と会話する:** 中央付近にいます。西側にいるゴブリンの群れについて事前に警告してくれます。
2. **大群を殲滅する:** ゴブリンの集団を倒し、南側のショートカット扉を開けて安全な撤退ルートを確保します。
3. **赤霧は慎重に対処:** 赤い霧を見かけたら、そのマスに踏み込む前に必ずパーティのHPを全回復させておきましょう。
4. **船頭を見つける:** 北東の角付近にいる船頭を利用すると、街まで一気に戻ることができます。
5. **出口を登録する:** 船頭を利用する前に、**山麓樹海（Sanroku Jukai Forest）**へと続く北東の出口に一度足を踏み入れましょう。次の迷宮のエリアに入ることで、街からの恒久的なファストトラベル地点として解放されます。

## よくある質問（FAQ）

### 赤霧の敵「Moto Inu」はどうやって倒せばいいですか？
Moto Inuは約20ダメージを与える強力な単体魔法を使用してきます。対策として、前衛が挑発スキルを使うか、1ターン目に集中攻撃を仕掛けて即座に倒しきりましょう。魔法使いのHPが低い場合は、敵の行動前に防御させるか回復アイテムを使用してください。

### 樹海への道の敵を無視して出口まで走り抜けることはできますか？
はい。通常のエンカウントは視認できる霧マスと連動しているため、通路の広さによっては灰色の霧や赤色の霧を迂回して避けることが可能です。ただし、主要な敵集団を倒すことで重要なショートカットが解放され、その後の探索が大幅に安全になります。

### 戦闘中にパーティの最大HPが減ってしまうのはなぜですか？
特定の**樹海への道の敵**と戦っていると、キャラクターが「墨の侵食」を受けることがあります。この状態になると、街の寺院で少額の金を払って浄化するまで最大HPが一時的に制限されます。

### 戦闘開始時に「攻撃」「様子を見る」「無視する」の選択肢が出たらどれを選ぶべきですか？
意図的にキャラクターのアライメントを善または悪に変化させたい場合を除き、常に**様子を見る（Wait）**を選択してください。パーティのアライメントに影響を与えることなく、通常の戦闘に移行できます。
