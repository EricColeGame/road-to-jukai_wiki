## ダンジョンの概要と基本システム

「樹海への道」は、本作における最初の試練となる場所です。終盤のマップと比較すると構造は比較的小規模ですが、序盤のパーティーは防御ステータスが低く、不注意なミスから簡単に立て直すための高位魔法も不足しています。

目に見えないランダムエンカウントが特徴の従来のダンジョンRPGとは異なり、本作のエンカウントは視認可能な「霧の塊」としてマップ上に直接出現します。これらの脅威を事前に見分ける方法を把握しておくことが、全滅を防ぐ鍵となります。

| エンカウントの霧の種類 | 危険度 | 出現する主な敵 | 推奨されるプレイヤーの行動 |
| :--- | :--- | :--- | :--- |
| **灰色の霧** | 低〜中 | 通常の雑魚敵、ゴブリン | 通常通り撃破。オート／リピートコマンドの使用も安全 |
| **赤色の霧** | 高〜致命的 | 中ボス、本犬、レアエネミー | 接触前にセーブ。HPを全回復し、単体攻撃魔法を準備 |
| **イベントアイコン** | 変動 / ストーリー | 衛兵、任意ボス（へっつい幽霊） | メッセージを注意深く読む。アライメントの選択肢を確認 |

通常の赤色の霧を含むほぼすべての敵シンボルは、ダンジョンから脱出するかフロア間を移動するとリスポーンします。[残月の鎖宮 Steamコミュニティハブ](https://store.steampowered.com/app/1922980/Labyrinth_of_Zangetsu/)のプレイヤー報告によると、序盤は赤色の霧との戦闘を慎重に避けることが、苦労して進めたダンジョンの進行状況を失わないための最善策とされています。

## 樹海への道 ステップ別攻略チャート

このエリアを探索するには、慎重な移動、隠し壁の発見、そして北東エリアの深部へ進む前に南側の門のショートカットを確保することが不可欠です。

```
[ 北西: へっつい幽霊 ] -------- [ 中央の番所 ] -------- [ 北東: 山麓樹海への出口 ]
          |                              |                                |
          |                      [ ゴブリンの大群 ]               [ 渡し守 / 帰還 ]
          |                              |                                |
[ 南西: 開始エリア ] ---------- [ ショートカットの門 ] --------------------+
```

### 1. 開始エリアと中央の交差点
南西エリアからダンジョンに入ったら、まずは時間をかけて行き止まりを隅々までマッピングしましょう。通路が隣の廊下に繋がらずに途切れているように見える場合は、壁に向かって**調べる／調べるボタン**を押し、隠された抜け道がないか探索してください。

フロアの中央に向かって進みます。中央付近には街道沿いに友好的な衛兵が配置されており、すぐ西側にモンスターの大群が集結しているという警告を聞くことができます。

### 2. ゴブリンの奇襲の突破
番所のすぐ西側には、固有のストーリー警告を伴う必須の灰色エンカウントが存在します。この戦闘では大規模な軍勢を相手にすることになります：

- **敵の編成:** 約10体の通常ゴブリンとゴブリンボス1体。
- **後衛への脅威:** 通常ゴブリンは後列を狙える遠距離攻撃を持っています。耐久力の低い魔法使いや回復役は、防御を固めるかHPを満タンに保ちましょう。
- **ボスの特徴:** ゴブリンボスは近接攻撃のみを行います。前衛の取り巻きが多数存在するため、ボスが近接攻撃の間合いに入るまで数ターンかかります。その間に周囲の雑魚敵の数を減らしましょう。

### 3. ショートカットの開通
ゴブリンの群れを殲滅したら、すぐに南へ進んで一方通行の門の鍵を解除してください。このショートカットを開くことで中央の大通りが開始エリアと直結し、休息や墨の浄化のために町へ戻る際の移動時間を大幅に短縮できます。

## 高脅威エネミーと任意エンカウント

本**樹海への道 攻略チャート**では、油断するとパーティーが一撃で全滅しかねない危険なモンスターをピックアップして解説します。

| 敵の名称 | 出現場所 | 危険度 | 戦略と弱点 |
| :--- | :--- | :--- | :--- |
| **ゴブリンの大群** | 番所の西 | 敵の数が多く後列を狙う | 全体・範囲攻撃を活用。通常のゴブリンから優先して撃破 |
| **本犬** | 徘徊する赤色の霧 | 1発あたり約20の魔法ダメージ | 低レベルの魔法使いが一撃死する危険性あり。強力な近接バースト攻撃で即座に集中攻撃 |
| **へっつい幽霊** | 北西の角（イベント） | 物理耐性が高く高火力 | 「はい」を選択すると戦闘開始。攻撃魔法を連打して撃破 |

### 北西イベントの攻略（へっつい幽霊）
最北西のマスではインタラクティブな選択肢が発生します。**「はい」**を選ぶと、任意の中ボスである**へっつい幽霊**との戦闘が始まります。
- この霊体に対して物理武器はほとんどダメージを与えられません。
- 呪文詠唱者に最も強力な属性魔法を使わせてください。
- この戦闘はフロアに入り直すことで何度でも再挑戦可能なため、呪文の消費リソースが安定した後の序盤の経験値稼ぎ・レベリング対象として非常に有効です。

## 重要な戦闘およびパーティー管理のコツ

『残月の鎖宮』で成功を収めるには、賢明なリソース管理が求められます。**樹海への道 攻略チャート**の進行中に以下の基本ルールを適用することで、パーティーを生存させ、適切なアライメントを維持できます。

### アライメント選択のジレンマ
戦闘開始時に**「戦う」**、**「様子を見る」**、**「見逃す」**という3つの選択肢が提示されることがあります。プレイヤーの検証により、これらの選択がキャラクターの性格（アライメント）に直接影響を与えることが判明しています：
- **戦う:** パーティーメンバーが**「悪」**に傾く確率が高い。
- **見逃す:** パーティーメンバーが**「善」**に傾く確率が高い。
- **様子を見る:** **アライメントの変化が発生しない**安全な選択肢。

意図しない転職資格の喪失やステータスペナルティを防ぐため、特定のアライメント変更を意図していない限りは、常に**「様子を見る」**を選択するのが確実です。

### 戦闘効率と墨の浄化
ターンの進行を早めるには、各戦闘ラウンドの開始時に**「リピート」**機能を使用し、前ターンの行動を自動実行させましょう。ただし、パーティーの最大HPの減少には細心の注意を払ってください。

墨に汚染された敵からダメージを受けると、キャラクターの最大HPが徐々に減少していきます（**墨の病**状態）。この状態異常はダンジョン内での通常の休息呪文では治療できません。町の寺院を訪れ、所定の手数料を支払って墨を浄化する必要があります。

| ゲームシステム | ゲーム内効果 | 推奨される対策 / 解決策 |
| :--- | :--- | :--- |
| **墨の病** | パーティーの最大HPが徐々に低下 | ダンジョン探索から帰還するたびに町の寺院で浄化する |
| **リピートコマンド** | 前ターンの行動を即座に再実行 | 通常の灰色の霧との戦闘で使用し、時間を短縮 |
| **フロア境界セーブ** | フロア切り替え時に状態をオートセーブ | 危険な赤色の霧に挑む前にフロア移動を挟んでセーブ |

## レベルアップシステムとリセット戦略

『残月の鎖宮』におけるレベルアップ時の成長にはランダム要素が含まれています。宿屋でキャラクターがレベルアップする際、主要ステータスはランダムに上昇するだけでなく、時には低下することもあります。

1. **オートセーブの仕組み:** ゲームはレベルアップ画面を見た瞬間にはステータス上昇を確定・保存しません。ただし、ダンジョンのフロアを移動したり、迷宮に入場した際にはオートセーブが行われます。
2. **ステータス厳選のテクニック:** 町でのレベルアップ時に主要キャラクターのステータスが大きく低下してしまった場合は、オートセーブが発生する行動を取る前に、即座にアプリケーションを強制終了（PC版ならAlt+F4）することができます。
3. **ステータス平準化の注意点:** 本作にはキャラクターの能力値を現在のレベル相応に自動調整しようとする内部仕様があります。序盤に無理やり最大ステータスを厳選すると、その後のレベルアップでステータス低下を引きやすくなります。この方法は乱用せず、急ぎで転職条件を満たしたい場合などに留めましょう。

## 山麓樹海への移行

本**樹海への道 攻略チャート**における最終目標は、北東の出口へ到達することです。

| ランドマーク | 場所 | 機能 |
| :--- | :--- | :--- |
| **渡し守** | 北東（出口付近） | 町への安全な即時ファストトラベルを提供 |
| **山麓樹海への入口** | 北東の移動口 | 第2のダンジョンを解放 |
| **ファストトラベル登録** | エリア境界 | ワールドマップに新しい森林ゾーンを登録 |

渡し守に話しかけて町へ戻る前に、**必ず一度は北東の境界を越えて山麓樹海へ足を踏み入れてください**。一度境界を越えることで、町の転移先に樹海が登録され、以降の探索で「樹海への道」を完全にスキップできるようになります。

## よくある質問（FAQ）

### 樹海への道の出口はどこにありますか？
次のダンジョンである「山麓樹海」へ続くメイン出口は、マップの**最北東の角**にあります。エリア境界のすぐ隣には、町まで直接送り返してくれる渡し守も配置されています。

### 最大HPが減少する「墨の病」はどうやって治しますか？
墨の病は、通常の回復薬や探索中の魔法では治療できません。町の拠点に戻り、**寺院**を訪れて少額の費用を支払うことでパーティーメンバーを浄化できます。

### 樹海への道にいる赤色の霧の敵はすべて倒すべきですか？
序盤の段階では、パーティーが万全な状態で休養を取っていない限り、赤色の霧とのエンカウントは避けるのが安全です。本犬のような敵は一撃で20以上の魔法ダメージを与えることがあり、後衛キャラクターが即死する危険があります。無用なリスクを冒す前に、必ず南側のショートカットを開通させておきましょう。
