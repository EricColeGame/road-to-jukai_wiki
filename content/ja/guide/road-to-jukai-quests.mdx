山麓の森の薄暗く入り組んだ道は、準備不足のパーティをあっという間に窮地に追い込みます。そのため、**樹海への道クエスト**を生き残るには明確なガイドが欠かせません。**樹海への道クエスト**をクリアするには、慎重なリソース管理、パズルの解決、そして手強い妖怪ボスとの的確な戦闘が求められます。隠されたアイテムを探している場合でも、貴重な実績の取り逃しを防ぎたい場合でも、この完全攻略ガイドが旅の各段階をステップ・バイ・ステップで解説します。

## ダンジョンの準備と必須呪文

山麓の樹海に足を踏み入れる前に、部隊の装備を適切に整える必要があります。『残月の鎖宮』のこの段階までに、呪文詠唱者は少なくともTier 2またはTier 3の魔法を使えるようにしておくべきです。呪文スロットは特定のTierごとに分かれているため、ボス戦用の高火力魔法を温存しながら、低Tierの補助呪文を自由に使用できます。

熟練プレイヤーの経験則によれば、補助魔法を活用することで消費アイテムを節約しつつ、ダンジョン探索の効率を大幅に向上させることができます。

| 呪文 / 道具 | クラス＆Tier | 主な用途 | 重要な理由 |
| :--- | :--- | :--- | :--- |
| **知覚上昇（Increase Perception）** | 僧侶（Tier 2） | 隠されたオブジェクトの強調表示 | 隠された木の根マスをパーティメンバーが自動で発見できるようになる |
| **光（Light）** | 僧侶（Tier 3） | 暗闇エリアの照明 | 迷宮を出るまで持続する明かりを確保する |
| **松明（Torches）** | 消費アイテム | 一時的な光源 | 僧侶のTier 3呪文スロットが不足している場合の予備手段 |
| **火属性範囲魔法** | 魔術師（Tier 2） | 範囲ダメージ | 一般的な植物系モンスターの弱点属性を突く |
| **疾風（Gale）** | 魔術師（Tier 4） | パーティの攻撃回数バフ | 長期化するボス戦で10ターンの間、攻撃ごとのヒット数を+1する |

森の東側エリアでは多数の暗闇マスに遭遇します。安定した光源を用意することで、パーティへの奇襲を防ぎ、罠によるダメージを最小限に抑えられます。

## 羽探し：北西の森セクター

**樹海への道クエスト**の序盤における主な目標は、北西（NW）ゾーン全体に散らばった紛失アイテムを回収することです。森の地面には入り組んだ木の根のマスが点在しており、近づくと調査プロンプトが発生します。

### 北西エリアの探索手順

1. **知覚を有効化：** フロアに入ったらすぐに僧侶のTier 2知覚上昇呪文を詠唱します。
2. **根のマスを調査：** 北西エリアにある入り組んだ木の根のポイントをすべてくまなく調査します。
3. **敵との遭遇に対処：** 根を調べると植物モンスターの奇襲を受けることがあります。Tier 2の火属性魔法を使って1ターンで殲滅しましょう。
4. **使用前に鑑定：** インベントリ内にある3つの羽を必ず鑑定してください。これは140種のアイテム図鑑実績の達成に直接貢献します。

| アイテム名 | 出現セクター | マスタイプ | 重要な注意点 |
| :--- | :--- | :--- | :--- |
| **失われた羽A** | 北西（NW） | 根の調査マス | クエストクリア前に必ず鑑定すること |
| **失われた羽B** | 北西（NW） | 根の調査マス | 弱い植物系モンスターに守られている |
| **失われた羽C** | 北西（NW） | 根の調査マス | 北側の外壁付近で発見可能 |

3つの羽をすべて安全に入手して鑑定を終えたら、マップの南東（SE）の隅へ向かい、羽を待っているNPCを探しましょう。

## 天狗の選択：分岐、戦闘、取り返しのつかない要素

南東の隅に到着すると、伝説の妖怪**天狗**に遭遇します。この会話は**樹海への道クエスト**における重要な分岐点であり、ゲーム全体で唯一の「真に取り返しのつかない実績」が含まれています。

彼に話しかける前に、一度迷宮を出て拠点（街）で手動セーブを行うことを強くお勧めします。

```
[南東の隅に到着]
        |
        v
[天狗と会話]
   /        \
  /          \
[羽を渡す]             [嘘をついて拒否する]
  |                        |
  v                        v
[平和的解決]             [ボス戦：天狗]
  |                        |
  v                        v
[魔法の羽を入手]         [取り返しのつかない実績を解除]
                           [魔法の羽をドロップ]
```

### 天狗の攻略法とステータス詳細

実績の100%コンプリートを目指す場合は、羽を見つけていないと天狗に嘘をつく必要があります。彼がさらに問い詰めてきたら、再び要求を拒否して戦闘を開始してください。

| ボスのアクション | 危険度 | 対象 | 対処法 |
| :--- | :--- | :--- | :--- |
| **風属性全体魔法** | 高 | パーティ全体 | 全体防御バフをかけるか、耐久の低い魔術師を即座に回復する |
| **単体強攻撃** | 致命的 | 味方単体 | HPを満タンに保つ。HPが0になった仲間は即座に蘇生・回復する |
| **通常近接攻撃** | 中 | 前列 | メイン盾役の防御バフを維持する |

*ダウン状態に関する注意点：* 『残月の鎖宮』では、HPが0になっても追加の追撃を受けない限り即座にロスト（完全な死亡）することはありません。倒れた仲間にはすぐに回復魔法を使用して戦線に復帰させましょう。天狗を撃破すると**魔法の羽**が手に入り、危険な北東セクターを安全に通行できるようになります。

## 暗闇セクターとポータルの探索

魔法の羽を手に入れたら、北東（NE）セクターへ向かいます。このセクターは深い暗闇に覆われており、無警戒に進むとパーティのHPを削る床のトラップが多数仕掛けられています。

| 危険要素 / ギミック | セクター位置 | 機能 | 推奨対策 |
| :--- | :--- | :--- | :--- |
| **暗闇マス** | 北東 | マップの視界を遮断 | 僧侶のTier 3「光」呪文を維持する |
| **床のスパイク罠** | 北東 | 継続的な小ダメージを与える | 慎重に歩を進め、定期的に回復する |
| **青緑色のポータル** | 中央 / 東 | テレポートネットワーク | 部隊を南・中央ゾーンへ転送する |
| **転移門** | 中央東寄り | フロア移動 | ボス部屋へ直接通じている |

迷宮各所にある青緑色のポータルはショートカットとして機能し、常に森の南中央の広場へとパーティを戻します。マーキングされた東の通路を見つけて奥の聖域へと進みましょう。

## ボス戦：八ツ凭（ヤツツキ）

境界線を越えるとフロア移動の自動セーブが発生します。内部の部屋はコンパクトで、2つの隠し部屋が存在します。北西の角にある隠し部屋には、パーティ全員のHPを全回復する**使い切りの回復の泉**があります（ただし呪文の使用回数は回復しません）。

**樹海への道クエスト**のクライマックスは、純粋な物理攻撃編成を苦しめる8本脚の巨大怪異**八ツ凭（ヤツツキ）**との決戦です。

| ボスフェーズ | ボスのアクション | 戦術的影響 | 最善の対策 |
| :--- | :--- | :--- | :--- |
| **バフフェーズ** | 硬化（自己バフ） | こちらの物理攻撃命中率を大幅に低下させる | 主に直接魔法によるバーストダメージに頼る |
| **回復フェーズ** | パッシブ自動回復 | 各ターン終了時にHPを一定割合回復する | 毎ターンの瞬間火力を最大化して回復量を上回る |
| **攻撃フェーズ** | 複数対象薙ぎ払い | 前列の防御役を削る | 2ターンごとに中位の全体回復を回す |

パーティがTier 4呪文を習得している場合は、戦闘開始時に**疾風**を唱えて前列の攻撃ヒット数を増やしましょう。八ツ凭が「硬化」を重ね掛けすると、物理武器でのクリーンヒットが難しくなります。詠唱者の残りの呪文Tierを惜しみなく注ぎ込み、ボスのHPを一気に削りきってください。

## 森の浄化：杭のメカニクス

八ツ凭を倒した後、広場の近くにいる生き残りのNPCと会話します。彼らから**浄化の杭**を受け取ることができ、これが**樹海への道クエスト**を完了させるために必要となります。

| 手順 | 必要なアクション | 危険度 | 結果 |
| :--- | :--- | :--- | :--- |
| **ステップ 1** | 灰色の煙の立ち上る場所を探す | 安全 | インタラクト可能な灰色の瘴気マスに近づく |
| **ステップ 2** | 黒い煙のマスを避ける | 危険 | 黒い煙を踏まないこと。致命的なトラップです |
| **ステップ 3** | 杭を打ち込む（3箇所） | 中 | 打ち込むごとにパーティにランダムで約10の反動ダメージが発生 |
| **ステップ 4** | 最後のNPC会話を発生させる | 安全 | NPCと話すことで街で次の迷宮が解放される |

杭を打ち込む前に、全パーティメンバーのHPが少なくとも15〜20以上残っていることを確認してください。残留する反動ダメージによって、低HPのキャラクターが思わぬ戦闘不能に陥る恐れがあります。3箇所の灰色の煙をすべて浄化したら、拠点となる街へ戻って次の道を開きましょう。システムの詳細な仕様、武器作成テーブル、クラスの育成ツリーについては、熟練のダンジョン探索者によって執筆された包括的な [Labyrinth of Zangetsu Steam Community Guides](https://steamcommunity.com/app/1922980/guides/) をご覧ください。

## よくある質問

### 天狗と戦わずに樹海への道クエストをクリアできますか？
はい、可能です。南東の角にいる天狗に失われた3つの羽を平和的に渡すことができます。その場合、天狗から直接「魔法の羽」を受け取れます。ただし、この選択をするとその周回では戦闘関連の限定実績が永久に取得できなくなります。

### 八ツ凭に物理攻撃がまったく当たらない場合はどうすればよいですか？
八ツ凭は頻繁に「硬化」を使用し、パーティの物理命中率を大幅に低下させます。これに対抗するには、主なダメージ源をTier 2やTier 3の攻撃魔法に切り替えるか、ボスが防御を固める前に「疾風」などの命中・攻撃回数バフを使用してください。

### クエスト完了前に羽を鑑定するとなくなってしまいますか？
いいえ、なくなりません。ショップやキャラクタースキルでクエストアイテムを鑑定しても、140種類のアイテム収集実績のために図鑑に登録されるだけです。使用するかNPCに引き渡すまで、クエストアイテムとしてインベントリに残り続けます。

### 灰色の煙を浄化する際になぜダメージを受けるのですか？
灰色の煙に浄化の杭を打ち込むと魔法的な反動が発生し、ランダムなパーティメンバーに約10ポイントの直接ダメージを与えます。各杭を作動させる前に、必ず部隊のHPをこのダメージライン以上に回復しておいてください。
