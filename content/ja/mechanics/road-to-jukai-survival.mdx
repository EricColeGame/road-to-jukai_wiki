## コアゲームプレイループ：夜勤の流れ

全6シフトを通じた全体的な目標は一見シンプルです。人里離れた町で乗客を乗せ、曲がりくねった山道を走り、指定された場所で降ろし、日の出まで生き残ることです。しかし、業務をこなすごとに周囲の環境によるプレッシャーは増していきます。

夜が進むにつれて霧は濃くなり、奇妙なラジオの異常が発生し、本当に人間なのか疑わしい乗客が現れます。車内の様子を常に監視しながら、車の操作を維持しなければなりません。

```
[配車リクエストを受諾] ➔ [乗客を確認して乗車] ➔ [山道をナビゲーション] ➔ [車内の異常に対処] ➔ [降車＆燃料補給]
```

### 必須のドライバーメーター

車両のコントロールと自身の安全を保つため、4つの主要な運行ステータスを監視する必要があります。

| メーター | 主な減少原因 | 回復方法 | 危険な影響 |
| :--- | :--- | :--- | :--- |
| **ドライバーの正気度 (Driver Sanity)** | 異常現象の直視、呪われた乗客 | 道路への集中、車内照明の点灯 | 幻覚、視界不良、操作不能 |
| **燃料残量 (Fuel Level)** | 走行距離、上り坂でのアイドリング | ガソリンスタンドの給油機、予備燃料缶 | 暗闇での立ち往生、エンジン停止 |
| **車両の耐久度 (Vehicle Integrity)** | コースアウトによる衝突、怪異との接触 | ロードサイド修理キット、整備士 | ヘッドライトの故障、車内への侵入 |
| **乗客のストレス (Passenger Distress)** | 乱暴なハンドル操作、スピードの出し過ぎ、過度な車内確認 | スムーズな運転、ラジオの周波数調整 | 暴走、超自然現象の顕現 |

これらの基本システムを理解することで、序盤のルート進行における生存率が大幅に向上します。

## 乗客の選別と後部座席の異常特定

日本の田舎の暗い道端でタクシーを待っている乗客のすべてが、生きた人間とは限りません。**Road to Jukaiのサバイバル**において最も重要な要素の1つが、ドアロックを解除する前に乗客候補を見極めることです。

視覚や聴覚の微妙な違和感に注目してください。人間の乗客は自然な呼吸を行い、会話の受け答えが成立し、タクシーのミラーに姿が映ります。悪霊や呪われた存在は乗客の行動を模倣しますが、見過ごせない超自然的な欠陥を抱えています。

### 乗客識別マトリクス

| 乗客タイプ | 視覚的特徴 | 音声の特徴 | 推奨される対処法 |
| :--- | :--- | :--- | :--- |
| **通常の通勤者** | 正常な呼吸、スマホや時計の確認 | 明瞭な声、ルート変更の要望 | 乗車を許可。スムーズに運転する |
| **彷徨える魂** | 青白い肌、ずぶ濡れの服、逸らされた視線 | 囁き声、繰り返されるすすり泣き | 注意して乗車させる。バックミラーを直視しない |
| **森のドッペルゲンガー** | 手足の不自然な痙攣、ミラーに映らない | 歪んだ音声、返答の遅れ | ドアをロックしたまま直ちに急加速して離れる |
| **樹海の幽霊** | 宙に浮いた姿勢、輪郭のノイズ | 完全な沈黙、または逆再生のような音声 | 車内用の清めの塩・お札を使用。車内を浄化する |

初期テスターの報告によると、怪異を後部座席に乗せてしまうと正気度が急速に低下します。誤って人ならざる者を乗せてしまった場合は、速度を一定に保ちながら車載の対策アイテムを使用し、深い森のエリアに入る前に車外へ排除しなければなりません。

## 車両のメンテナンスと山道の危険要素

あなたのタクシーは、樹海の奥に潜む恐怖から身を守る唯一のシェルターです。車のメンテナンスを怠れば、確実に命を落とすことになります。曲がりくねった山道には、自然の運転リスクだけでなく、物理的な道路レイアウトを歪める呪われた環境トラップも存在します。

ヘッドライトの作動状態を維持することは極めて重要です。『Road to Jukai』では、光が届かなくなると、周囲の森がアスファルトの上へと侵食してきます。

### 危険要素の脅威分析

| 道路の危険要素 | 察知方法 | 回避策 / 対処法 | 危険度 |
| :--- | :--- | :--- | :--- |
| **深い樹海の霧** | ダッシュボードの温度計が急低下 | ロービームの使用、速度を落とす | 中 |
| **偽の迂回路** | GPSの点滅、ガードレールの消失 | 紙の地図と照合、怪しい標識を無視 | 高 |
| **影の障害物** | 前方の道路を塞ぐ遠くの人影 | ハイビームを3回パッシング。急ブレーキは厳禁 | 極めて高い |
| **電気系統のブラックアウト** | メーター類の針が激しく回転 | 手動クランクで再始動、ヒューズを交換 | 高 |
| **路肩の亡霊** | サイドミラーに映る動き | 前方のみを注視。絶対に車を停めない | 低 |

## シフト別のサバイバル進行ガイド

キャンペーン全体を生き残るには、段階的に激しさを増す怪奇現象に適応していく必要があります。第1夜で通用したルールも、第5夜には役に立たなくなります。以下は、各シフトで何を優先すべきかを示した戦術的な進行ロードマップです。

### 夜勤シフト別 攻略ガイド

| シフト | 主な注力点 | 新登場の要素 | 生存のための重要戦略 |
| :--- | :--- | :--- | :--- |
| **第1夜：通勤** | ルートの把握と車両の操作感覚 | 基本的な乗客の送迎、燃料消費 | 町と町を結ぶ主要なショートカットを覚える |
| **第2夜：囁き声** | 正気度管理とラジオのチューニング | 音声の異常、ミラーの反射 | アイコンタクトを避けるため車内灯を消しておく |
| **第3夜：深林の乗客** | 怪異の選別 | 人間以外の乗車リクエスト | ドアを開ける前に必ずサイド・バックミラーで確認 |
| **第4夜：推測航法** | ナビゲーションの判断力 | GPSの故障、変化する交差点 | 物理的な目印や道路標識を暗記する |
| **第5夜：侵食** | 防衛運転と車内の浄化 | 怪異による車内への直接侵入 | 緊急用対策アイテムを常に最大まで補充しておく |

後半の夜では、ルート選びの効率が極めて重要になります。危険な心霊ゾーンを避けるために曲がりくねった迂回路を選ぶと燃料を浪費し、街灯のない暗闇の道路で立ち往生するリスクが高まります。

## 上級サバイバル戦術と実践のコツ

ゲームを完全に攻略するには、ハンドルを握りながらの細かなリソース管理が不可欠です。安定して**Road to Jukaiのサバイバル**を成功させるために、以下の実戦的なテクニックを取り入れてください。

1. **バックミラーの「チラ見」をマスターする**：バックミラーを2秒以上連続で見つめないでください。直視し続けるとパニックが加速し、怪異を刺激します。乗客の状態を素早く確認したら、すぐに視線を道路に戻しましょう。
2. **カーバッテリーの節約**：人気のない降車地点で停車中は、車内灯やラジオなどの補機類を切ってください。バッテリーが上がると完全な暗闇の中で手動押しがけを強いられ、森の脅威に無防備な姿を晒すことになります。
3. **環境音の変化に耳を澄ます**：カーラジオは早期警戒探知システムとしても機能します。ノイズの急増やリズミカルなクリック音は、道路沿いの至近距離に強力な怪異が存在することを示しています。
4. **適正速度を維持する**：恐ろしい怪異からスピードを出して逃げたくなるかもしれませんが、雨で濡れた日本の峠道でスピードを出しすぎると激しいドリフトやタイヤロックを引き起こし、致命的なクラッシュにつながります。
5. **塩のストックを管理する**：各地のガソリンスタンドで、護符や清めの塩を補充しておきましょう。車内での怪異発生時、後部座席の足元に塩を撒くことで貴重な時間稼ぎができます。

## よくある質問（FAQ）

### 『Road to Jukai』のサバイバルで最も重要なメカニクスは何ですか？
最も重要なのは、車内の正気度管理と乗客の厳密な選別です。ドアのロックを解除する前に乗客をよく確認しないと、怪異を車内に招き入れることになり、急速に正気度が削られて致命的な運転事故を引き起こします。

### 偽物や幽霊の乗客はどのように見分ければよいですか？
鏡に姿が映らない、呼吸のリズムが異常、目が光っている・歪んでいる、音声が途切れ途切れであるなど、不自然な視覚・聴覚の異常を探してください。通常の通勤者に見えない場合は、絶対にドアを開けてはいけません。

### 森の中で車がエンストした場合はどうすればよいですか？
森の怪異から注意を逸らすため、すぐにヘッドライトを消してください。サイドブレーキを引き、手動クランクでエンジンを再始動します。エンジンがかかるまでは車内灯も消したままにしておきましょう。

### 紙の地図を使わずにクリアすることはできますか？
序盤のシフトではダッシュボードのデジタルGPSが機能しますが、後半の夜になると強い電磁障害が発生して電子機器が狂います。終盤のナビゲーションでは、実際の道路標識と紙の地図を頼りに進むことが不可欠です。
