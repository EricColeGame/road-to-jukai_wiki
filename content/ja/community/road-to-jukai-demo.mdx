## 『Road to Jukai』とは？ 概要とパブリッシャー最新情報

『Road to Jukai』は、夜勤の運転業務という日常的な緊張感と、日本の伝承をモチーフにしたサイコロジカルホラーを融合させた作品です。Endflameが開発しtinyBuildがパブリッシングを手がける本作で、プレイヤーは深夜勤務のタクシー運転手となり、鬱蒼とした不気味な樹海に隣接する日本の孤立した山里の間で、地元住民や謎の乗客を送り届けます。

[Gematsuのパブリッシング発表記事](https://www.gematsu.com/2026/09/road-to-jukai-formerly-silent-road-to-be-published-by-tinybuild)で報じられた開発者アップデートによると、本プロジェクトは初期開発段階の『Silent Road』から大幅に進化を遂げ、現在のテーマ性を持つ作品へと結実しました。

| ゲーム属性 | 詳細 |
| :--- | :--- |
| **開発元** | Endflame |
| **パブリッシャー** | tinyBuild |
| **旧タイトル** | *Silent Road* |
| **ジャンル** | 一人称視点サイコロジカルホラー / ドライブシミュレーター |
| **対象プラットフォーム** | PC (Steam) |
| **製品版リリース年** | 2027年 |
| **現在の提供状況** | Steamプレイテスト / 体験版ビルド |

物語は6つの異なる夜を通じて展開します。安易なジャンプスケア（脅かし要素）だけに頼るのではなく、環境ストーリーテリング、ラジオのノイズ、ノンリニアな物語進行、そして次第に不気味さを増していく乗客とのやり取りを通じて、心の奥底から湧き上がる恐怖をじっくりと構築していきます。

## コアゲームプレイシステム：夜勤を生き延びるために

**Road to Jukai 体験版**をプレイすると、そのゲームプレイの仕組みが単なるウォーキングシミュレーターよりもはるかに緻密であることが分かります。リアルな車両操作と周囲の警戒を同時にこなすマルチタスクを強いられることで、独特の緊張感が生まれます。

```
       [ タクシー営業所：乗車依頼を受注 ]
                    │
                    ▼
     [ 曲がりくねった樹海の山道を走行 ]
       ├── ルームミラーを注視
       ├── ヘッドライトとワイパーを管理
       └── 乗客の会話に耳を傾ける
                    │
                    ▼
       [ 超常現象・心理的イベントが発生 ]
       ├── 道端に現れる怪異
       ├── 乗客からの不穏な要求
       └── 車両システムの不具合
                    │
                    ▼
        [ 無事に乗客を降ろすか、脱出する ]
```

### 主要なゲームプレイ要素

1. **前方への注視：** 日本の狭い田舎道を運転するには、正確なハンドル操作、突然の路上障害物への警戒、そして豪雨時のワイパーや氷点下の夜のデフォッガー（曇り止め）といった車両システムの管理が求められます。
2. **夜勤業務：** 乗客ごとに異なる物語が存在します。疲れ切ったサラリーマンもいれば、人間ではないかもしれない何者かも乗り込んできます。会話の受け答えを適切に行い、ルームミラーを頻繁に確認することで、背筋の凍るような異変に気づくことができます。
3. **去らぬ死者たち：** 樹海の境界を進むにつれ、超自然現象は激しさを増していきます。プレイヤーはどのルートが安全かを見極め、彷徨う霊の注意を引かないように立ち回らなければなりません。

| システム | ゲーム内での役割 | 脅威 / ホラー的影響 |
| :--- | :--- | :--- |
| **ルームミラー** | 後部座席の乗客を監視 | 乗客の姿勢が変化したり、忽然と姿を消す |
| **ハイビーム / ロービーム** | 道路の障害物や標識を確認 | 濃霧でハイビームが遮られる／路傍の怪異を照らし出す |
| **無線 / 配車システム** | 乗客の乗車位置座標を受信 | 原因不明の周波数の乱れや幻聴 |
| **燃料＆車両の耐久度** | 車両の走行可能な状態を維持 | 故障すると完全な暗闇の中で立ち往生する |

## システム要件と最適化のヒント

**Road to Jukai 体験版**をスムーズなフレームレートでテストするには、お使いのPCが推奨ハードウェアスペックを満たしているか確認することをおすすめします。ボリュメトリックフォグや動的な車両ライティングは、旧世代のグラフィックカードにとって負荷が高くなる場合があります。

| ハードウェア構成 | 最小要件 | 推奨スペック |
| :--- | :--- | :--- |
| **OS** | Windows 10 (64-bit) | Windows 11 (64-bit) |
| **プロセッサー** | Intel Core i5-6600K / AMD Ryzen 5 1600 | Intel Core i7-9700K / AMD Ryzen 7 3700X |
| **メモリ** | 8 GB RAM | 16 GB RAM |
| **グラフィックカード** | NVIDIA GTX 1060 (6GB) / AMD RX 580 | NVIDIA RTX 3060 / AMD Radeon RX 6700 XT |
| **DirectX** | Version 11 | Version 12 |
| **ストレージ** | 15 GB の空き容量 | SSDへのインストールを強く推奨 |

### 動作安定化のためのおすすめ設定

- **ボリュメトリックフォグを「中」に設定：** ミドルレンジのGPUにおいて、周囲の不気味な雰囲気を損なうことなく大幅なFPS向上が見込めます。
- **フレームレートを60FPSに固定：** 狭い道でのハンドル操作中に画面酔いを防ぐため、フレームレートの安定性は極めて重要です。
- **空間オーディオの有効化：** 乗客のかすかな身動きや道端の環境音を聞き取るため、空間オーディオを有効にしたステレオヘッドホンの使用を推奨します。

## よくある質問（FAQ）

### 『Road to Jukai』の体験版は完全に無料でプレイできますか？
はい。現在の**Road to Jukai 体験版**およびSteamプレイテストビルドは、Steamの公式製品ページからアクセスをリクエストしたすべてのプレイヤーに無料で提供されています。

### 『Road to Jukai』の製品版はいつ発売されますか？
パブリッシャーのtinyBuildおよび開発元のEndflameは、PC版の製品版リリース時期を2027年内と発表しています。発売時期が近づくにつれて、追加のプラットフォーム展開が発表される可能性があります。

### 『Silent Road』というゲームはどうなったのですか？
『Silent Road』は、Endflameが初期開発段階で使用していた仮タイトルです。tinyBuildとのパブリッシング契約締結に伴い、現在の『Road to Jukai』へと正式に改名されました。

### 『Road to Jukai』体験版はコントローラーやハンコン（ステアリングコントローラー）に対応していますか？
現在のプレイテストでは、マウス＆キーボード操作に加えて標準的なコントローラーを完全サポートしています。専用のレーシングホイール（ハンコン）サポートについては、テスト期間中のプレイヤーからのフィードバックをもとに開発チームが検討を進めています。
