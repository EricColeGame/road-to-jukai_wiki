## 『Silent Road』からの進化：タイトルの刷新と基本コンセプト

tinyBuild Connect Showcaseで発表される前、本作はインディーゲームファンの間で『Silent Road』というタイトルで知られていました。『Road to Jukai』への改名は、富士山麓に広がる歴史的な「樹海（青木ヶ原樹海）」を明確に想起させ、作品が持つ文化的雰囲気とテーマ性をより際立たせるための意図的な変更です。

```
+-------------------------------------------------------------------+
|                        ROAD TO JUKAI                              |
|                   深夜タクシー運転シミュレーション                    |
+---------------------------------+---------------------------------+
|                                 |                                 |
|      🚕 ドライビングシステム       |      👥 乗客との遭遇             |
|   • ルート管理                  |   • 会話の選択肢                |
|   • 天候に応じた運転            |   • 不穏な乗客からの要求        |
|   • 車両システムのメンテナンス  |   • マルチエンディング展開      |
|                                 |                                 |
+---------------------------------+---------------------------------+
```

プレイヤーには、人里離れた狭い山道で深夜のタクシーを運行する任務が課せられます。戦闘やクリーチャーから逃走することに焦点を当てた従来のアクションホラーとは異なり、本作の緊張感は孤独感、車内という閉鎖空間での乗客とのやり取り、そして不気味で情緒的なストーリーテリングから生まれます。

| 機能の概要 | Silent Road（初期コンセプト） | Road to Jukai（現行ビルド） |
| :--- | :--- | :--- |
| **開発元** | Endflame | Endflame |
| **パブリッシャー** | インディー / 未発表 | tinyBuild |
| **主な舞台** | 日本の一般的な田舎の裏道 | 樹海／青木ヶ原周辺の道路 |
| **コアゲームプレイ** | 探索 / ドライブ | ナラティブタクシーシム / サイコホラー |
| **対応プラットフォーム** | PC | PC（Steamプレイテスト実施中） |
| **リリース予定時期** | 未定 | 2027年 |

リブランディングによって、ゲームプレイに織り込まれた超自然的な伝承の要素が一層強調されることになりました。濃霧と曲がりくねった山道を進むなかで、乗客の目的、ひいてはその存在自体が現実のものかすら定かではない状況にどう対応するか、慎重な判断が求められます。

### 樹海エリアの走行

本作における運転には、常に細心の注意が求められます。プレイヤーはミラーを確認し、滑りやすい路面で適切な速度を維持しながら、突然発生する環境の異変に対処しなければなりません。初期テスターからのコミュニティ報告によると、ドライビングフィジックスはアーケード風の操作感ではなくリアルなシミュレーション寄りに調整されており、急な天候変化や超常的な路上ハザードに直面した際の緊張感をより高めています。

| 車内パーツ・機能 | システム上の役割 | ホラー演出への影響 |
| :--- | :--- | :--- |
| **ルームミラー** | 後部座席の乗客を監視 | 視覚的な異常現象や予期せぬ動きの確認 |
| **ダッシュボード無線** | ナビゲーションと配車連絡の受信 | ノイズの混入や意味深な音声シグナル |
| **ヘッドライト** | 車両前方の道路を照射 | 濃霧による周辺視野の制限 |
| **料金メーター** | 走行距離と進行状況の記録 | 怪異現象の発生時に不審な挙動を示す |
| **ウィンドウ開閉** | 車内の換気と視界確保 | 外の環境音や気配が車内へ侵入 |

### 乗客の挙動と分岐するストーリー展開

乗車してくる客には、それぞれ独自の物語が存在します。「車内の明かりを消してほしい」「地図にない脇道へ入ってほしい」といった不穏な要求に応じるか拒否するかによって乗客の反応が変化し、ストーリーの展開や遭遇する危険要素が分岐していきます。

## 技術仕様とゲームエンジンの特徴

Endflameは、日本の人里離れた森林地帯を深夜にドライブする圧倒的な臨場感を再現するため、高精度な空間オーディオとダイナミックライティングを導入しています。最新の開発状況の確認やプレイテストへの参加登録は、現在アクセス管理が行われている[Road to JukaiのSteam公式ストアページ](https://store.steampowered.com/)から直接行うことができます。

| システム要件 | 最小スペック（予測） | 推奨スペック（目標） |
| :--- | :--- | :--- |
| **OS** | Windows 10 (64-bit) | Windows 11 (64-bit) |
| **プロセッサー** | Intel Core i5-8400 / AMD Ryzen 5 2600 | Intel Core i7-10700 / AMD Ryzen 7 3700X |
| **メモリ** | 8 GB RAM | 16 GB RAM |
| **グラフィック** | NVIDIA GTX 1060 / AMD RX 580 | NVIDIA RTX 3060 / AMD RX 6600 XT |
| **DirectX** | Version 12 | Version 12 |

開発陣によると、広大な森林マップのシームレスな読み込みや、突発的な超常演出をカクつきなく描画するためには、特にSSD（ソリッドステートドライブ）の利用が効果的であるとのことです。
